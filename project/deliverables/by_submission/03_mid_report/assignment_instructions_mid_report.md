## Grading rubric

| Section | Weight | What the mark is based on |
|---|---:|---|
| 1 - Introduction | 10% | A **testable question with numbers**, etc. A clear statement looks like this: *a detector interval is congested when its mean speed is below __ m/s, or its occupancy above __ %, for at least __ consecutive intervals.* **Put the GitHub repository link at the end of this section.** |
| 2 - Model and parameters | 25% | Equations; each parameter with its value; boundary; etc. |
| 3 - Results so far | 25% | Plots / drawings / figures / visualizations |
| 4 - Challenges | 15% | The challenges encountered during the project, both **resolved and unresolved**. Explain how we addressed the ones we have overcome and our plans for the remaining ones |
| 5 - Timeline | 10% | **Dated tasks** up to the final paper |
| References; Appendix: contribution statement and AI use | 15% | |

## Format (same as the final submission)

- 1-inch margins; font **Times New Roman, no smaller than 11 pt**.
- Title: project title, **team number**, each student's **name and course number**.
- Numbered sections, in the order above. Numbered figures and tables, with captions.
- **IEEE** citation style.
